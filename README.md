# CS50


This repository contains my work, projects, and implementations completed while studying **Harvard University's CS50's Introduction to Artificial Intelligence with Python**.

Throughout the course, I explored the fundamental concepts of Artificial Intelligence by building algorithms and solving real-world problems using Python. The course covers both classical AI techniques and introductory machine learning, providing a strong foundation for modern AI systems.

## Topics Covered

* Search Algorithms (Depth-First Search, Breadth-First Search, Uniform Cost Search, Greedy Best-First Search, A*)
* Knowledge Representation and Propositional Logic
* Logical Inference and Model Checking
* Constraint Satisfaction Problems (Backtracking, AC-3)
* Adversarial Search (Minimax and Alpha-Beta Pruning)
* Probability and Bayes' Rule
* Bayesian Networks
* Markov Chains and Hidden Markov Models
* Machine Learning Fundamentals
* Supervised and Unsupervised Learning
* Neural Networks and Deep Learning Basics
* Computer Vision and Convolutional Neural Networks (CNNs)
* Natural Language Processing (NLP)
* Model Evaluation and Cross-Validation
* Ethics in Artificial Intelligence

## Technologies Used

* Python
* NumPy
* pandas
* scikit-learn
* TensorFlow / Keras
* NLTK
* OpenCV / Pillow
* Matplotlib

## Repository Contents

This repository includes solutions, experiments, assignments, and projects developed throughout the course. Each project demonstrates a different AI concept, from search and logical reasoning to probabilistic models, machine learning, computer vision, and natural language processing.

By completing this course, I gained practical experience with:
